What is js

javascript is a programming language that enables you to create interactive web pages.
It allows developers to add functionality to websites, such as animations, form validation, and more.
JavaScript is a versatile language that can be used for web development, mobile app development, game development

variables

variables are used to store data in a program.
by default they were undefined

rules to write variable name

  • can not use reserved keyword
  • should be meaningful names
  • can not start with umbers
  • can not contain spaces or special characters except underscore _
  • camel notation is used for variable names (firstName)
  • they are case-sensitive

Types of variables

  • var
  • let
    • block scope
    • can re - assign
  • const
    • block scope
    • can not re-assign

types of dataType

  1. Primitive type
    • string -- let name = 'sharon';
    • number -- let age = 21;
    • boolean -- let isApproved = false;
    • undefined
    • null
  2. reference type
    • objects -- let person = {name: 'sharon', age: 21};

      • chaning the properties of objects

      • dot notation -- person.name = 'sharon';
        syntax -- objectName.propertyName = 'value'
      • bracket notation -- person['name'] = 'jessy'
        syntax -- objectName['propertyName'] = value
    • arrays -- let fruits = ['apple', 'banana', 'cherry'];
      []; -- array literal
      acessing elements -- using index
